# Integrated Project Delivery (IPD) Readiness Assessment Tool

A data-driven, interactive decision-support prototype engineered to evaluate organizational and procurement readiness for Integrated Project Delivery (IPD) frameworks within Canadian public-sector infrastructure environments.

This application translates qualitative institutional, cultural, and contractual conditions identified in academic literature into quantitative deployment readiness indicators. This tool functions as a digital planning gatekeeper, helping public owners evaluate their systematic alignment with collaborative contracting methods (such as the Canadian Construction Documents Committee CCDC 30 multi-party form) prior to formal capital allocation.

## 📊 Core Features

* **Multi-Party Diagnostic Engine:** Evaluates a project ecosystem across four fundamental thematic axes: Procurement Flexibility, Governance Delegation Capacity, Organizational Collaboration Maturity, and Shared Risk-Reward Acceptance.
* **Dynamic Visual Analytics:** Generates real-time, interactive radar alignment charts to map stakeholder synergy and flag fragmentation risks instantly.
* **Programmatic Recommendation Roadmaps:** Automatically outputs targeted, localized execution pathways (e.g., Institutional Legislative Reform, Hybrid Collaborative Transitions, or Direct CCDC 30 Execution) based on calculated mathematical scoring boundaries.

## 🛠️ Technological Stack

* **Language:** Python
* **Interface Framework:** Streamlit (Open-source web application framework)
* **Data & Visualization Engineering:** Matplotlib, NumPy, Pandas
